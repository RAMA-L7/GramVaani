# Workflow-mapping template — one complete anonymized reporting task

**Purpose:** capture one real reporting task end-to-end as a reusable, anonymized workflow map (research evidence only).  
**Use:** observation-first; complete during/after a permitted observation session. Do **not** introduce GramVaani or demo/test a prototype while mapping the existing workflow.  
**Anonymization:** participant/centre codes only (e.g. W__, C__). **No** beneficiary/child data, no names, no centre names/addresses, no Aadhaar/IDs, no phone numbers, no credentials, no photos/screenshots containing identifying information. Describe artifacts and field labels only; never copy values.
